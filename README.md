# 🌐 노원 DDNS & 포트 통합 관리 대시보드

50여 개의 현장 DDNS 주소와 포트(`80`, `554`, `8080~8083`) 상태를 **한 번에 병렬로 실시간 측정(TCP 포트 열림 + 공유기 ICMP Ping)**하고 관리하는 웹 대시보드입니다.

## ✨ 주요 기능
- **초고속 병렬 측정**: 40~50개 지점의 DDNS IP 조회, TCP 포트 연결, 공유기 Ping을 **약 1.5~2초 내**에 동시 체크
- **정밀 장애 원인 구분**:
  - `DDNS 도메인 IP 조회 실패` (공유기 전원 꺼짐 / DDNS 만료)
  - `공유기 Ping은 정상, 포트(80/554/808x) 닫힘` (인터넷은 정상이나 하위 카메라/장비만 점검 필요)
  - `포트 열림 (온라인)` (정상 작동 및 응답 속도 ms 표시)
- **원클릭 웹 접속**: 웹 포트(`80`, `8080~8083`) 항목은 `[🔗 웹접속]` 버튼으로 즉시 장비 페이지 오픈
- **엑셀 복사/붙여넣기 호환**: 엑셀에서 `[명칭 | ddns 주소 | 포트]` 열을 복사해 그대로 일괄 등록 가능

## 🚀 실행 방법 (Windows PC)

별도 패키지 설치(`pip install`) 없이 Python 기본 내장 라이브러리만으로 즉시 작동합니다.

1. **`DDNS_모니터_실행.bat`** 파일을 더블 클릭합니다.
2. 자동으로 브라우저가 열리며 `http://127.0.0.1:8765` 대시보드가 표시됩니다.
3. **같은 사무실 공유기/와이파이를 쓰는 팀원**은 콘솔 창에 표시되는 `같은 네트워크(팀원)` 주소(예: `http://192.168.x.x:8765`)로 접속하면 프로그램 설치 없이 함께 볼 수 있습니다.

## ☁️ 외부 링크로 팀원에게 웹 배포하기 (Render.com 무료 배포)

사무실 밖에서도 팀원들이 URL 링크 하나로 접속하게 하려면 GitHub 저장소를 **Render.com**에 연결하세요:

1. [Render.com](https://render.com) 로그인 후 **New +** → **Web Service** 클릭
2. 이 GitHub 저장소를 연결
3. 아래 설정 입력:
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python server.py --no-browser`
4. 생성된 `https://xxxx.onrender.com` 링크를 팀원에게 카카오톡/슬랙으로 공유하면 끝!
